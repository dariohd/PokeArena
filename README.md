# PokeArena

Combat de figurines Pokémon en **2.5D** dans le navigateur — data live **PokéAPI**.

| | |
|---|---|
| **Prod** | https://pokearena-topaz.vercel.app |
| **Stack** | Vite · TypeScript · Phaser 3 · PokéAPI |

## Jouer

```bash
npm install
npm run dev
```

→ http://localhost:5173

- **ZQSD / flèches** : déplacement
- Attaque auto au contact
- Recrute les vaincus (chance selon combo)
- 12 vagues · stats & sprites PokéAPI
